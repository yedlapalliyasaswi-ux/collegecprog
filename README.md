# collegecprog
RANDOM SHIT COLLEGE PROGRAMS
**important for mid 1**
*Unit-1*
1. Convert (156)10 into binary, octal and hexadecimal.
2. Convert (1011011)2 into decimal, octal and hexadecimal.
3. Convert (3F7)16 into binary, octal and decimal.
4. Convert (725)8 into binary, decimal and hexadecimal.
5. Illustrate the four steps of computational thinking.
6. Explain algorithm, pseudocode and flowchart with the symbols used in a flowchart.
7. Illustrate different types of operators and operator precedence in C.

*Unit-2*

1. Illustrate the different types of conditional statements in C with syntax and a short
example for each.
2. Illustrate the different types of looping statements in C with syntax and a short
example for each.
3. Illustrate the different types of jumping statements in C with syntax and a short
example for each.
4. Illustrate one-dimensional arrays with declaration, initialization, memory
representation and element access.
5. Illustrate two-dimensional arrays with declaration, initialization, memory
representation and element access.
6. Write a C program to check whether a given number is positive, negative or zero.
7. Write a C program to check whether a given number is Armstrong or not.
8. Write a C program to find sum and average of array elements.
9. Write a C program to search given element using linear search.
10. Write a C program to perform matrix addition.

*Unit-3*

1. Illustrate how strings are represented in C with declaration, initialization.
2. Write a program to read a string and find its length using strlen().
3. Write a program to compare two strings using strcmp() and print whether they are
identical or not.
4. Illustrate string-handling functions in C with syntax and a suitable example for each.
